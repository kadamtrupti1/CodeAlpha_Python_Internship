
# CodeAlpha Python Programming Internship

**Python Programming Internship Projects – CodeAlpha**

This repository contains four Python projects completed as part of my CodeAlpha Python Programming Internship.

## Projects

### Task 1 – Hangman Game
A text-based word guessing game where the user guesses letters to find a randomly selected word within a limited number of attempts.

**Concepts:** Random module, loops, conditional statements, strings and lists.

### Task 2 – Stock Portfolio Tracker
A Python program that calculates stock investment values based on stock prices and quantities entered by the user. Portfolio details are saved in a CSV file.

**Concepts:** Dictionaries, lists, loops, calculations and CSV file handling.

### Task 3 – JPG File Organizer
An automation script that identifies JPG images in a source folder and moves them into a separate destination folder.

**Concepts:** OS module, Shutil module, file handling and automation.

### Task 4 – Basic Chatbot
A simple rule-based chatbot that responds to user messages using predefined conditions and replies.

**Concepts:** Functions, loops, user input and conditional statements.

## Technologies Used
- Python
- CSV File Handling
- OS Module
- Shutil Module

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code or PowerShell.
4. Run the required task using:

```bash
python task1.py
python task2.py
python task3.py
python task4.py
```

Run one command at a time.

**Note:** Task 2 uses sample stock prices. Task 3 requires a folder named `MyPhotos` containing JPG images in the same directory as the script.
